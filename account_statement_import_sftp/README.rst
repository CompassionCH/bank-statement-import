This module imports bank statement files that an EDI backend gets from
an SFTP server.

**Table of contents**

.. contents::
   :local:

Configuration
=============

1. Create an EDI backend with the backend type *Bank SFTP Import* and an
   FS storage (sftp). Set its input pending directory.
2. For each kind of file, create an input exchange type for this backend
   type, with a filename pattern (for example ``^camt\.053.*\.xml``).
3. Set *Receiver* to the storage handler and *Processor* to *EDI
   handler: import bank statement files*.

Usage
=====

The EDI scheduled actions find the new files on the server, get them and
import them as bank statements. A file that cannot be imported (unknown
format, or only transactions already imported) gets the error on its
exchange record.

The statement lines are posted when they are created, so the old
``import_statement_edi_auto_post`` system parameter is not used any
more.
